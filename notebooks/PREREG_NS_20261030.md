# PREREG_NS_20261030 [STAMPED JM 2026-10-30 13:49 "accepted"; FROZEN]

Drafted 2026-10-30 14:10 (JM 13:31 "can you set up the run? - it's only watt hours"). Posterior-sampling follow-up to PREREG_MARG_20261030 (MAP), as owed in sec 3.1 of draft v2.0.1. Script marg_ns_20261030.py (dynesty nested sampling; same harness as the MAP fit, which reproduces pass2 to 3e-9).

## 1. Questions
Q1 With distances, inclinations and mass-to-light ratios treated as nuisance parameters with their published priors, does the evidence prefer the relation at one universal rho_c, or the empirical RAR function? (The MAP fit gave equal rms, 0.057 vs 0.056, but larger distance shifts for the relation. The Bayes factor weighs those shifts against the priors automatically.)
Q2 How much intrinsic scatter in log g does each description need? (Profile over a fixed intrinsic-scatter value added in quadrature to the velocity errors.)
Q3 Is a per-galaxy rho_c justified by the evidence once nuisances are marginalised, or does the extra parameter cost more than it buys?

## 2. Arms, priors, likelihood (frozen)
Arms: U = relation, rho_c = 10^7.45 universal; B = empirical RAR function, g_dagger = a0; A = relation, log rho_c flat on [6, 10] (run only at sig_int = 0).
Priors (all arms): log Ud ~ N(log 0.5, 0.1 dex); log Ub ~ N(log 0.7, 0.1 dex) for bulge galaxies; D ~ N(D_SPARC, e_D) truncated at 0.2 D_SPARC; i ~ N(i_SPARC, e_i) truncated to [20, 90] deg.
Likelihood: Gaussian in velocity, variance ev^2 + (sig_int v ln10 / 2)^2, i.e. intrinsic scatter sig_int in log g; sig_int in {0, 0.03, 0.06} for arms U and B. Same point selection as the note (Q<=2, i>=30, ev/v<0.1; 147 galaxies, 2696 points).
Sampler: dynesty NestedSampler, nlive 250, dlogz 0.1, multi-ellipsoid bounds, random-walk sampling; per-galaxy evidence error ~0.1-0.3, so the summed error over 147 galaxies is ~1.5-3.5.

## 3. Metrics
M1 Delta logZ(U - B) summed over galaxies, at each sig_int; and the count of galaxies with |Delta logZ| > 2.5 either way.
M2 For each arm, the sig_int that maximises the summed logZ over {0, 0.03, 0.06} (coarse profile of the intrinsic scatter), with the summed logZ differences between the three values.
M3 Delta logZ(A - U) summed, at sig_int = 0: the evidence for per-galaxy rho_c over universal rho_c, extra parameter penalised.
M4 Posterior-median z_D (distance shift in prior sigmas) per galaxy, each arm: rms and the count beyond 2; the posterior 16-84 width of z_D (how much the data constrain D at all).
M5 Posterior-median residual rms per arm (comparable to the MAP numbers 0.057 / 0.056 / 0.045).

## 4. Decision rules (fixed now)
D1 (Q1, at the sig_int preferred by each arm in M2): summed Delta logZ(U - B) > +5 -> evidence FAVOURS the universal-rho_c relation; < -5 -> FAVOURS the empirical function; otherwise INDISTINGUISHABLE. (ln 5 ~ 'strong' on the Jeffreys scale; the summed evidence error is below this.)
D2 (Q2): the relation's preferred sig_int is reported beside the empirical function's; if the relation at universal rho_c prefers sig_int >= 0.06 while the empirical function prefers <= 0.03, the scatter tension is CONFIRMED at the posterior level; if both prefer the same value, it is NOT CONFIRMED.
D3 (Q3): Delta logZ(A - U) > +5 -> per-galaxy rho_c is SUPPORTED by the evidence; < -5 -> NOT SUPPORTED; otherwise INDIFFERENT.
D4 Credibility of distance shifts: the universal arm's count of galaxies with posterior-median |z_D| > 2 is compared with the empirical function's; more than 1.5x is reported as 'bought with distances', and D1 is then reported with that qualifier whatever its sign.
D5 Nothing is adopted on the result; sec 3.1 and sec 8 of the note are updated to report it.

## 5. Pre-stated expectation
D1 INDISTINGUISHABLE or mildly favouring B (|sum| < 5), because the MAP rms were equal and the distance shifts cost prior probability. D2: both arms prefer sig_int = 0.03 (NOT CONFIRMED), since Li et al. found the RAR's MAP residual consistent with errors. D3 INDIFFERENT to SUPPORTED (the MAP chi^2 drop from U to A was 3400 for ~147 extra parameters). D4 triggered (U ~ 1.5-2x B), as in the MAP fit.

## 6. Cost and procedure
Pilot (done, 2 galaxies, nlive 200): arm B ~1-5 s per galaxy; arm U ~8,000-75,000 likelihood calls per galaxy at ~0.015 s each, i.e. 2-20 min per galaxy per sig_int on one core. Full run: U at 3 sig_int values + A at one ~ 200 core-hours; on the 5950X with --procs 30, roughly 6-8 hours. Output is one JSON line per (galaxy, arm, sig_int) and the run resumes if interrupted. Metrics script: marg_ns_metrics_20261030.py (to be written against the pilot file before the full run).
Command (from notebooks/ in a clone of gprf-v2 with SPARC fetched, or in the gprf repo):
  pip install dynesty
  nohup python3 marg_ns_20261030.py --arms UBA --sig 0,0.03,0.06 --procs 30 > marg_ns_run.log 2>&1 &
