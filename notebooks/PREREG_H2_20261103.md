# PREREG_H2_20261103 -- molecular-gas omission test on the HERACLES x SPARC subset
Written 2026-11-03 17:05 EST BEFORE any code. [UNRATIFIED] until JM stamps. Trigger: JM 16:34 "ok for the sentence - curious to try the vm run".

## 1. Question
SPARC baryon models omit H2. The note's new sec 3 sentence claims: (i) the omission is of order the M/L uncertainty in the inner parts of massive spirals; (ii) at fixed M/L it biases g_bar low there (so log(g_obs/g_model) high); (iii) with M/L free it is largely absorbed. Does adding measured H2 change any fixed-nuisance number the note reports, and in the stated direction?

## 2. Inputs (fixed)
- SPARC rotmod + Lelli 2016c table, as in pass2_sparc_full_20261022.py (M/L 0.5 disc, 0.7 bulge; HI x 1.33; Lelli-style point selection; 10% velocity weights).
- H2: Leroy et al. 2009 (AJ 137, 4670) Table 3: L_CO(2-1) and CO exponential scale length l_CO per galaxy; M_H2 = 5.5 L_CO (their eq. 3: X_CO = 2e20, R21 = 0.8, helium 1.36 included). File data/heracles2009/leroy2009_table3.csv (transcribed from ar5iv; unverified vs journal PDF).
- Rescaling to the SPARC distance D_s: M_H2 x (D_s/D_L)^2, l x D_s/D_L.
- H2 radial model: razor-thin exponential disc, Sigma_0 = M_H2/(2 pi l^2); v_H2^2(r) = 4 pi G Sigma_0 l y^2 [I0 K0 - I1 K1](y), y = r/2l (Freeman 1970). Added to v_bar^2; M_b += M_H2 (so sigma rises through eq. 2).
- Sample: the 9 SPARC galaxies in Table 3 with CO detections: NGC 2841, 2903, 2976, 3198, 3521, 4214, 5055, 6946, 7331. NGC 2841 and 4214 have no reliable l_CO: use 0.2 r25 (Leroy 2009 mean), flagged. IC 2574, DDO 154 (upper limits) excluded.
- Solver: solve_gal of pass2_sparc_full (frozen law R1, ambient 35.5 subtracted, S = 2 tanh(x/2), sigma^2 = sqrt(G a0 M_b)/2), copied with the two extra inputs only. Universal rho_c = 10^7.45.

## 3. Quantities, both WITHOUT and WITH H2, per galaxy
Q1 log rho_c from the 1-D rho_c-free fit at fixed M/L, and its chi^2 (Table 2 'law' column).
Q2 At universal rho_c: median log(g_obs/g_model) over inner points (g_bar >= a0) and over outer points (g_bar < a0).
Q3 Same residuals for the empirical function at fixed M/L.
Q4 chi^2 of the empirical function with Y_disc free (Table 2 'rfree'), for the per-galaxy winner against Q1.
S1 (supplementary) law with rho_c AND Y_disc free: Delta log rho_c with H2 when M/L can absorb it.

## 4. Criteria (fixed now)
K1 median over the 9 of Delta log rho_c (with - without) in [-0.3, 0.0]. Expectation -0.1 dex.
K2 the 9-galaxy median inner residual (Q2) moves toward zero: |with| <= max(0.02, 0.5 |without|). Expectation: +0.05 -> ~0.
K3 the per-galaxy winner (law rho_c-free vs empirical function Y-free, by chi^2) flips in <= 2 of 9, and the summed-chi^2 ordering over the subset is unchanged.
K4 median |Delta chi^2|/chi^2 for the law (rho_c free) < 30%.
Decision: all pass -> "the omission does not affect the reported conclusions; sentence stands" (one clause may add the measured size). K2 fail with the residual GROWING -> the sentence's bias-direction clause is wrong: retract it. K3 fail -> Table 2 / B.3 need an H2 caveat for massive spirals. K1 outside the range -> report the surprise; no text change without a JM ruling.
Not a pass/fail on the relation: the comparison models see the same baryons, so no evidence number in the note changes in principle; this test measures the fixed-M/L sensitivity only.
